# Sarah Alshammari — Developer Portfolio

Bilingual Arabic/English portfolio with a white, black and olive identity, system typography (Thmanyah files excluded pending web-embedding permission), and responsive layouts. Built with HTML, CSS and JavaScript; no framework or build step.

## Run locally

Open `index.html` in a modern browser, or from this directory run:

```sh
python -m http.server 8000
```

Visit http://localhost:8000. VS Code Live Server also works.

## Deploy on GitHub Pages

In the repository open **Settings → Pages**. Select **Deploy from a branch**, choose **main** and **/(root)**, and save. GitHub will show the deployed URL after the deployment completes.

## Content

- Arabic content and layout: `index.html`
- English translations and language toggle: `app.js`
- Responsive styles: `style.css`
- Provided project screenshots, font references: `assets/`

The language preference is saved locally in the visitor's browser. Project images switch with the language and open in accessible native dialogs. Experience sections expand using native details elements. Contact uses an email link. The full résumé is intentionally excluded pending explicit approval for public distribution.

Sila links to its public repository. Farz displays a screenshot preview because its repository is private. No live project URLs were supplied; add them when the applications are deployed. Screenshot files still show the ExpoGreen product name for the Farz project.

Fonts and project screenshots were supplied by the portfolio owner; retain their applicable usage rights. Design direction is inspired by Tamal Sen’s portfolio structure, with original implementation and content.
